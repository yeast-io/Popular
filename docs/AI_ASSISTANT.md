# AI Assistant

This is how the AI Assistant works

| 顺序 | 新能力 | 届时新增的数据 |
|---|---|---|
| 讨论 | 使用上下文生成回答 | 会话标识、选取的历史消息 |
| 资源 | 找到电影并查询资源 | 当前电影 ID、资源列表引用 |
| 推荐 | 读取偏好并生成候选 | 偏好、候选电影、推荐批次 ID |
| 下载 | 创建待确认操作并恢复执行 | 待确认操作 ID、确认结果 |


```mermaid
flowchart TD
    U["用户<br/>查《降临》的资源"]
    C["通信工具<br/>Telegram / WhatsApp"]
    I["消息接入层<br/>识别用户、消息去重"]

    U --> C --> I

    subgraph W["Workflow：控制流程、保存状态、暂停与恢复"]
        R{"当前是否在等待确认？"}
        A["Agent<br/>理解需求、选择查询工具<br/>根据结果组织回答"]
        T["工具执行层<br/>校验参数、用户权限<br/>调用业务服务"]
        D{"下一步"}
        P["保存待确认下载单<br/>绑定用户、具体资源、有效期"]
        V["校验用户确认<br/>防止过期和重复执行"]
        E["执行下载<br/>记录真实提交结果"]
        O["生成回复<br/>查询结果 / 确认请求 / 执行结果"]

        R -->|普通请求| A
        A -->|提出工具调用| T
        T -->|返回真实数据| A
        A -->|完成本轮判断| D
        D -->|查询完成| O
        D -->|需要用户补充信息| O
        D -->|请求下载| P
        P --> O
        R -->|收到对应确认| V
        V -->|有效| E
        V -->|无效或已处理| O
        E --> O
    end

    I --> R

    B["现有业务服务<br/>电影、偏好、资源、下载"]
    DB[("数据库 / 外部平台<br/>MongoDB、TMDB、资源平台、下载器")]

    T --> B
    E --> B
    B <--> DB

    O --> S["通信发送层<br/>将回复发回原会话"]
    S --> U
```
