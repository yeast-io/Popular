# 验证记录

执行日期：2026-10-20。执行环境：macOS Apple Silicon，Rust 1.96.0、Node.js 24.13.0、pnpm 12.10.1。

## 已通过

- `pnpm build:ui`：Vue / TypeScript 类型检查与 Vite 生产构建通过。
- 针对实验目录的根 ESLint 检查通过。
- `cargo check`、`cargo test`（2 项：会话/序号校验、双语资源一致性）、`cargo clippy -- -D warnings` 通过。
- `pnpm test:mock`：真实 loopback WebSocket 测试通过，确认心跳响应与非法业务消息拒绝。
- `pnpm tauri build --debug --bundles app`：成功生成 macOS Apple Silicon `.app`。最终构建报告调试应用 27.76 MiB；不代表发布体积或内存占用。
- 原生程序启动时不创建设置窗口，Rust 后台立即连接本地模拟服务。
- 再次运行应用激活已有设置窗口；模拟服务只有原连接，没有创建第二个后台实例。
- 通过原生界面确认中英文切换成功；关闭后再次打开设置仍为中文。
- macOS Keychain 写入虚构测试凭据并立即读回验证成功，界面清空输入，不返回已存凭据。
- 重新编译、退出并重启后，原生界面确认“已保存并验证”；跨进程读取通过。随后删除虚构测试凭据，界面确认“无已存凭据”。
- 自动启动开关由关闭变为开启，再关闭，界面与系统注册状态一致。测试结束保留关闭状态。
- 关闭设置窗口后，模拟服务继续收到同一 session 的多次 30 秒心跳；重新打开设置后进程 ID 相同，累计确认数增长。
- 终止并重启模拟服务，原生客户端自动恢复同一进程会话，重连计数增加。
- 从应用菜单退出后，模拟服务观察到连接断开。

## 待验证

- 重新登录后的自动启动；本次没有注销用户会话。
- Windows 构建与原生行为。
- 正式签名、公证、升级后的凭据访问。

## 范围限制

只验证框架生命周期、原生存储与 loopback 传输，不验证正式 WSS、API Key / 设备签名协议、下载器、排队与下载状态同步。本次未测试容量或测量常驻内存。Socket / 原生测试使用明确获准的本地网络权限；最初沙箱禁止监听导致的一次测试失败，不是协议测试失败。

重编译后的第一次 Keychain 读取曾延迟约 30 秒，随后命令正常完成；再次启动同一构建后读取立即成功。自动化工具不允许检查 SecurityAgent，因此没有确认这次延迟的系统原因。正式发布仍需验证稳定签名下的凭据访问，不能把本次实验当作升级兼容性保证。

测试结束：原生客户端与本地模拟服务已退出，自动启动已关闭，虚构测试凭据已删除；中文偏好保留。所有项目改动都在本实验目录中。
