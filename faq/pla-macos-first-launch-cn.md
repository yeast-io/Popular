# macOS 首次打开 Popular Link Agent

**安装后若提示“Apple 无法验证 Popular Link Agent 是否包含恶意软件”，请按下面步骤在系统设置中允许打开。** 安装与首次打开预计需要 2–3 分钟，不含下载时间。

### 为什么出现提示

目前发布的 Popular Link Agent（PLA）尚未完成 Developer ID 签名和 Apple 公证。macOS 可能显示 **“Popular Link Agent” Not Opened**，并且弹窗中只有 **Done（完成）** 按钮。

这表示系统无法完成安全验证，不等于已经检测到恶意软件，也不证明应用安全。仅在确认文件来自本项目发布页、且信任该来源时继续。

### 安装与首次打开

1. 从 [Popular 发布页](https://github.com/yeast-io/Popular/releases) 下载对应 PLA 版本的 `pla-<版本号>-universal.dmg`。该包用于 Apple Silicon 和 Intel Mac；`pla-<版本号>.zip` 是 Windows 包。测试版会标记为 Pre-release。
2. 双击 DMG，将其中的 **Popular Link Agent.app** 拖入 Finder 的 **应用程序（Applications）** 文件夹。
3. 从“应用程序”中双击 PLA。若出现无法验证的提示，点击 **完成（Done）** 关闭弹窗。
4. 打开 **系统设置 → 隐私与安全性**，向下滚动到“安全性”区域，找到 PLA 被阻止的提示，点击 **仍要打开（Open Anyway）**。
5. 按系统要求验证身份，并在再次出现的确认弹窗中点击 **打开（Open）**。

完成后，系统会为这个应用保存例外，通常可直接双击再次打开。更换或更新安装包后，可能需要再次确认。不同 macOS 版本的按钮名称和位置可能略有不同。

### 确认已经运行

查看屏幕顶部菜单栏是否出现 PLA 图标。没有显示窗口时，点击菜单栏图标打开菜单，再打开设置，按照界面填写 Gateway 地址、用户 API Key 和下载器配置。

关闭设置窗口后，PLA 会继续在菜单栏运行；要结束程序，请使用菜单中的退出选项。

### 遇到问题

| 情况 | 操作 |
| --- | --- |
| 找不到“仍要打开” | 再从“应用程序”双击 PLA，关闭拦截弹窗，然后重新查看“隐私与安全性”。 |
| 按钮不可用，或公司电脑禁止放行 | 联系设备管理员；受管理设备可能限制这项操作。 |
| 提示“将损坏你的电脑”、已检测到恶意软件，或“应用已损坏” | 停止打开，不按本教程强行放行。保留完整提示、PLA 版本和 macOS 版本，向项目维护者反馈。 |
| 放行后仍闪退或无法运行 | 记录 PLA 版本、macOS 版本、Mac 芯片类型和完整错误信息，向项目维护者反馈；这需要进一步排查。 |

无需关闭 Gatekeeper、开启“任何来源”或执行删除隔离属性的终端命令。本教程只说明如何对可信来源的 PLA 添加单个应用例外。

依据：[Apple 官方：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。手动放行不等于通过 Apple 公证。
